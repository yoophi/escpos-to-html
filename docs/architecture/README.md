# 아키텍처 검토

이 디렉터리는 ESC/POS Receipt Emulator의 deepening 후보와 적용 결과를 기록한다. 문서는 후보의 현재 마찰, 유효한 seam, interface가 test surface가 되기 위한 조건, 그리고 결정 전에 해소할 질문을 보존한다.
